# Sports Equipment Tracker — نظام تسيير المستلزمات الرياضية

تطبيق سطح مكتب محلي (يعمل دون اتصال بالإنترنت) لإدارة متجر للمستلزمات الرياضية:
المنتجات، المخزون، المبيعات، الصادرات والطلبات، المصاريف والأرباح، الموردون والديون،
التقارير، النسخ الاحتياطي، والمستخدمون والإعدادات.

- الواجهة بالعربية مع تخطيط من اليمين إلى اليسار (RTL).
- كل المبالغ تُعرض بالدينار الجزائري (دج / DZD).
- منصة الاستهداف: Windows 10 / Windows 11 (يمكن التطوير على أي نظام).

## التقنيات

| الطبقة | التقنية |
| ------ | ------- |
| سطح المكتب | Electron |
| الواجهة | React + TypeScript |
| البناء والتطوير | electron-vite (Vite) |
| التوزيع | electron-builder |
| قاعدة البيانات | SQLite — ستُضاف في المرحلة القادمة |

لا يوجد أي اعتماد على خادم بعيد أو خدمة سحابية وقت التشغيل.

## بنية المشروع

```
sports-shop/
├── src/
│   ├── main/        # عملية Electron الرئيسية (نافذة، IPC، الأمان)
│   │   ├── index.ts     # إنشاء النافذة ومسجلات IPC
│   │   └── security.ts  # تعزيز الأمان (تنقل، نوافذ منبثقة، صلاحيات)
│   ├── preload/     # جسر contextBridge — واجهة desktop المحددة صراحةً
│   ├── shared/      # أنواع مشتركة بين العمليتين (تنقل، عقود IPC)
│   └── renderer/    # واجهة React العربية RTL
│       ├── src/components/  # Sidebar, TopBar
│       ├── src/views/       # لوحة التحكم + صفحات مؤقتة للأقسام
│       └── src/lib/format.ts # تنسيق المبالغ بالدينار الجزائري
├── electron.vite.config.ts
└── electron-builder.yml
```

## الأمان

إعدادات Electron الافتراضية الآمنة مطبَّقة عمداً:

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- لا يتم تصدير أي وصول إلى Node.js أو نظام الملفات إلى الواجهة؛ فقط
  واجهة `window.desktop` المعرفة صراحةً في `src/preload/index.ts`.
- سياسة CSP صارمة في `src/renderer/index.html` (مصادر محلية فقط).
- منع التنقل الخارجي والنوافذ المنبثقة وطلبات الصلاحيات (`src/main/security.ts`).

## تشغيل التطبيق (وضع التطوير)

```bash
cd sports-shop
npm install
npm run dev
```

يفتح نافذة Electron مع دعم إعادة التحميل الفوري (HMR).

## الأوامر المتاحة

| الأمر | الوصف |
| ----- | ----- |
| `npm run dev` | تشغيل التطبيق في وضع التطوير |
| `npm run typecheck` | فحص أنواع TypeScript (main/preload/shared و renderer) |
| `npm run build` | فحص الأنواع ثم بناء حزم الإنتاج إلى `out/` |
| `npm run start` | معاينة نسخة البناء الحالية |
| `npm run build:win` | إنشاء حزمة تثبيت Windows (NSIS) — تُنفَّذ على Windows |
| `npm run lint` | فحص ESLint |
| `npm run format` | تنسيق الشيفرة بـ Prettier |

## خارطة الطريق

1. **المرحلة الأولى (الحالية):** هيكل التطبيق، أمان Electron، واجهة عربية RTL،
   شريط تنقل بالأقسام العشرة، وصفحات مؤقتة.
2. **المرحلة القادمة:** إضافة SQLite في العملية الرئيسية، وتوسيع عقد
   `DesktopAPI` في `src/shared/electron-api.ts` بطرق IPC مكتوبة الأنواع.
3. لاحقاً: المنتجات، المخزون، المبيعات، نقطة البيع، الباركود، التقارير، النسخ الاحتياطي.
